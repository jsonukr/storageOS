## Chapter 08 – User Personas

**Document ID:** V1-CH08

## Purpose

Define representative users to guide product decisions, UX, and feature prioritization.

---

## Persona 1 – Dhananjay (Power User)

**Profile**
- Uses multiple PCs, a work laptop, phone and cloud storage.
- Frequently switches between personal and office environments.

**Goals**
- Find files instantly.
- Monitor all storage in one place.
- Transfer files between devices without friction.

**Pain Points**
- Doesn't remember where files are stored.
- Uses multiple storage applications.
- Duplicates consume space.

**Key Features**
- Unified Explorer
- Universal Search
- Storage Dashboard
- Duplicate Finder
- Drag & Drop Transfers

---

## Persona 2 – Priya (Freelancer)

**Profile**
Works with multiple clients and cloud providers.

**Goals**
- Keep client workspaces separate.
- Share files securely.
- Sync work automatically.

**Key Features**
- Workspaces
- Permissions
- Sync Rules
- Sharing

---

## Persona 3 – Rahul (IT Administrator)

**Profile**
Manages users, devices and storage for an organization.

**Goals**
- Visibility across devices.
- Audit activity.
- Enforce security policies.

**Key Features**
- Device Management
- RBAC
- Audit Logs
- Health Monitoring

---

## Persona 4 – Sarah (Creative Professional)

**Profile**
Photographer/video editor managing terabytes of media.

**Goals**
- Quickly locate media.
- Move large files between NAS and cloud.
- Analyze storage growth.

**Key Features**
- Storage Analyzer
- Transfer Queue
- Large File Detection
- Media Search

---

## Persona Summary

Every feature should solve a real problem for at least one defined persona.
